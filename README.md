# 周末有去处 · Weekend Nearby

面向家庭的周末出行指南静态网站。可按距离、出发城市、星期六 / 星期日、免费与室内条件筛选本地活动、附近去处和园艺栏目，并查看详情、收藏和亲子园艺任务。

本站通过 GitHub Pages 从 `main` 分支的根目录发布：

https://berserker123.github.io/weekend-nearby/

## 文件

- `index.html`：可直接打开的完整单文件网页（样式、脚本和插画已内联）。
- `source/`：便于修改的源码，含 `index.html`、`style.css`、`app.js` 与 `assets/` 插画。
- `使用说明.txt`：本地打开与使用说明。
- `.nojekyll`：让 GitHub Pages 按原样提供文件，不经过 Jekyll 处理。

活动与地点以页面内标注的来源为准，出发前请核对官网。天气卡片为演示内容。收藏、任务和投稿草稿只保存在浏览器本机。
