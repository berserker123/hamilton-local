# 便民黄页 MVP：Google 表单提交、人工审核、静态数据发布

便民黄页上线时所有分类都没有数据。作为一个人维护的站点，我们要用最低维护成本让商家自己提交，同时保证信息真实。沿用 ADR-0001：黄页是服务类 Category 的 Place 视图，数据仍是带 schema 的静态 JSON，不引入后端、数据库或 CMS。

## 决定

- **提交渠道**：商家通过一个 Google 表单提交，回复进 Google 表格。新增和修改用同一个表单，修改时勾选「修改已有条目」并填写条目名称，走同样的审核。
- **表单内容**：联系人邮箱只用于审核和续期，不在网站公开；商家必须勾选同意公开其余信息才能提交。商家英文名必填。地址一栏填「服务区域或店铺地址」，上门服务的商家可以只写服务区域，不需要门牌号。链接一栏可以是网站、Google 地图、小红书或 Facebook 主页。
- **审核标准**：至少一个独立 Source 与提交的信息对得上才上线，记为 verified；对不上就退回，不上线。有店铺地址的，核对地址和电话；只填服务区域的，核对商家名称和电话（待定，见下）。审核通过的条目由人工转成 Place JSON，先做预览，负责人说「上线」后才发布。
- **分类**：网站固定 4 个分类页、13 个小分类，商家只能从中选择：
  - 房屋维护：园艺与庭院、房屋维修、清洁整理
  - 专业工种：水管服务、电工服务、木工与油漆
  - 生活便民：搬家运输、生活协助、社区服务
  - 专业顾问：金融服务（贷款、保险、理财）、移民中介、会计、律师

  表单另有第 14 项「其他服务」，网站上没有这个分类。选了「其他服务」的提交先不上线，也不硬塞进现有小分类，在回复表里记下服务类型；同一类攒够后，由负责人决定是否新增小分类，加了之后再按同样的审核上线。宠物指南里的寄养、洗护美容、狗狗日托不在表单里，暂时保留原来的「商家入驻 / 广告合作」入口。
- **过期与下线**：Verification date 超过 90 天即 Stale（ADR-0001），前端显示提示；Stale 后再过 30 天仍未重新核验，自动从页面隐藏，数据保留，重新核验后恢复。没有 Verification date 的条目直接隐藏。规则在 `source/src/place-status.ts`，有真实商家后再接到页面上。
- **重新核验**：每月列出快到期的条目名单和请商家确认的邮件草稿，负责人审核后才发送；商家确认后再对照 Source 核验一次，更新 Verification date。
- **下架**：商家提出下架时，先通过提交时登记的联系邮箱核实是商家本人，再下架。Record ID 永久保留，不复用。
- **双语**：缺中文简介时用 AI 翻译补上并标「机器翻译」，商家确认后去掉该标记；缺英文时按 ADR-0001 回退显示中文，不硬翻。
- **空分类**：显示「内容整理中」，每个小分类和页面底部都有「免费入驻」按钮，直接打开 Google 表单（`source/src/services-config.ts`；表单链接清空时按钮改成发邮件）。
- **排序**：同一分类内按名称排序，不设付费置顶。有真实商家后，「免费入驻」占位排在真实商家后面。
- **收费**：上线初期全部免费。以后如收费，只按月或按年，不做一次性买断，届时另写 ADR。
- **重新评估门槛**：条目超过 200 条，或每周提交超过 20 份时，重新评估是否引入数据库或 CMS。

## 待定

1. **「其他服务」攒到多少家才加新小分类**：负责人看到时再定，暂不设固定数字。
2. **只填服务区域的商家怎么核实**：没有门牌号时，用什么 Source 才算对得上（如 Google 地图商家页、NZBN、官网或社交主页上的同一个电话）。
3. **专业顾问是否要查执照**：移民中介、金融服务、律师、会计是否要求在对应的官方注册名单里查到才上线。
4. **宠物 3 类**：是否加进表单。

## Considered Options

- **轻量数据库或 CMS（如 Airtable、Notion、Decap）让商家直接编辑**：省去人工转录，但多一套账号、权限和费用要维护，且绕过人工核验，与「每条都附来源」相冲突。
- **只留合作邮箱**：零成本，但格式不统一，每条都要来回问字段。
- **Tally 表单**：功能接近，但 Google 表单与现有 Google 账号和表格直接打通，少一个服务。
- **提交后先上线标「待确认」**：上架快，但会让未经核验的信息出现在读者面前。

## Consequences

- 每条新增、修改、下架都要人工处理和发布，数量增长后人工成本上升，由上面的重新评估门槛兜底。
- 前端需要支持：按 Verification date 推算 Stale 和 30 天后隐藏、「机器翻译」标记、空分类的「免费入驻」按钮（已上线）。
- 表单字段需要与 Place schema 一一对应，转录时才不会丢字段或产生并列字段。
- 联系邮箱属于个人信息，只存在 Google 表格里，不进入公开数据文件。
